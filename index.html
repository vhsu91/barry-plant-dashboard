Connect Your Google Sheet

Follow these 4 steps — it's all copy and paste, no coding needed.

1
Open your Google Sheet. Click Extensions → Apps Script.
2
Delete everything in the editor and paste this code:
function doGet() { const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0]; const data = sheet.getDataRange().getValues(); const json = JSON.stringify(data); return ContentService.createTextOutput(json) .setMimeType(ContentService.MimeType.JSON); }
3
Click Deploy → New deployment.
Type: Web app · Execute as: Me · Who has access: Anyone
Click Deploy, authorise, then copy the Web app URL.
4
Paste the Web app URL below and click Connect.
URL should start with https://script.google.com/macros/s/ and end with /exec
